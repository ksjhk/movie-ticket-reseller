# 卡世界电影票代理分销 API

面向电影票代理商、分销平台、私域电商、SaaS 服务商和开发者。电影货源覆盖 359 个城市。代理预充值后，通过 API 密钥接入影片、影院、场次和座位资源，在自己的网站、小程序、公众号或分销系统中自主定价并销售赚差价。

本仓库提供电影票代理介绍、对接文档和 DeepSeek Harness 插件，不附带商城源码或其他业务资料。

## 代理怎么做这门生意

1. 注册卡世界开放平台账号，创建代理密钥并预充值。
2. 查询城市、影片、影院、场次和座位，将电影货源接入自己的销售渠道。
3. 根据场次成本、目标客群、渠道费用和售后成本自主制定售价。
4. 客户在你的渠道选座下单后，你的服务端调用电影票代理 API 锁座并创建订单。
5. 平台按实际订单成本扣除预充值余额，继续执行出票。
6. 出票成功后向客户提供取票码；出票失败按结果处理退款。
7. 销售价与代理结算成本之间的差额构成代理毛收入，实际利润还需扣除支付、营销和售后等成本。

代理掌握自己的客户、售价和销售渠道。卡世界提供电影货源、锁座下单、自动出票、订单查询与失败退款能力。

## 已具备的能力

- 覆盖 359 个城市的电影货源。
- 热映与待映影片、影院、放映日期、场次和座位图查询。
- 代理密钥、预充值余额、锁座下单与自动出票。
- 出票状态查询和取票码返回。
- 出票失败自动退款，便于代理对账和售后。
- 电影只读查询支持匿名调用；下单、订单查询和余额查询必须签名。

## 适合哪些 B 端业务

- 已有用户和订单渠道，需要增加电影票品类的分销平台。
- 需要统一电影货源与出票接口的 SaaS 服务商。
- 运营公众号、小程序、社群或企业福利渠道的代理商。
- 希望自建电影票分销系统、掌握定价权的开发团队。

## DeepSeek Harness 插件

插件只适用于 **DeepSeek Harness（DSH）**，普通 DeepSeek 手机 App 和网页聊天版不能安装。保留原仓库地址，纯 JavaScript，无 TypeScript 或构建步骤。

```bash
dsh plugin --profile web add github:ksjhk/movie-ticket-reseller
```

安装后提供 3 个工具：电影货源统一查询、订单查询、锁座并创建订单。统一查询覆盖城市、影片、影院、场次和座位图等 12 个只读接口，匿名可用；订单工具需要代理自己的密钥：

```bash
export KASHIJIE_APP_KEY='你的 app_key'
export KASHIJIE_APP_SECRET='你的 app_secret'
```

Mock 或自托管接口可通过 `KASHIJIE_MOVIE_API_BASE_URL` 覆盖默认 API 根地址。

自然语言使用示例：

> 查询北京的热映影片、影院场次和可售座位，按代理成本整理。
>
> 先让我核对场次、座位和订票手机号，等我明确同意后再锁座下单。

**锁座下单会真实扣除代理预充值余额。** 插件要求下单工具显式传入 `confirm: true`，未确认不会发请求；网络超时先查单，不重复下单。完整字段与签名规则仍见 [电影票代理 API 文档](docs/api.md)。

## 对接流程

```text
代理注册并预充值
→ 查询城市、影片、影院和场次
→ 获取场次与座位图
→ 在自己的渠道自主定价
→ 服务端签名锁座并创建代理订单
→ 查询出票状态
→ 返回取票码或失败退款结果
```

完整接口、字段、签名算法和调用示例见 [电影票代理 API 文档](docs/api.md)。
